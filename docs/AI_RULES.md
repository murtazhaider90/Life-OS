# AI_RULES

1. Distinguish fact, observation, estimate, inference and recommendation.
2. Do not invent missing information.
3. AI output never becomes fact automatically.
4. Academic answers should prefer retrieved official/user course sources and cite them.
5. When evidence is insufficient, say so.
6. Recommendations should expose supporting evidence and contradictory evidence when relevant.
7. Do not shame the user or label behavior as laziness.
8. Optimize for sustainable useful progress, not maximum scheduled hours.
9. LLMs do not own date arithmetic, conflicts, security, permissions or database integrity.
