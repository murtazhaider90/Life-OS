# SYSTEM

The Personal AI Life OS is a private single-user planning and academic-learning system. Its primary question is: given verified commitments, academic requirements, current state, previous behavior and available time, what is the most useful next action, and why?

Current foundation:
- Phase 1: provenance-aware tasks, calendar, study sessions, course ingestion/retrieval and deterministic daily planning.
- Phase 2: privacy-minimal activity telemetry, explicit activity rules, low-friction state inputs and deterministic session metrics.
- Phase 3: versioned weekly planning, dynamic replanning, minimum viable week, study-attempt/weak-topic evidence, morning briefing and weekly review.

Behavioral inference remains evidence-bound: no inference is silently promoted to fact, missing context stays missing, and significant comparisons include sample counts/status.
